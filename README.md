# 照片检测工具 / Photo Tamper Detector

一个纯前端的网页工具，用于检测照片是否被 P 图（贴图、拼接、涂抹、重新保存）修改过。

**单文件、零依赖、照片不上传** —— 所有分析在你的浏览器本地完成。

[![License: MIT](https://img.shields.io/badge/License-MIT-blue.svg)](LICENSE)

## 在线使用

直接下载 `index.html`，双击用浏览器打开即可（支持 Windows / macOS / Android / iOS）。

也可以放在任意静态托管（如 GitHub Pages）后在线使用。

## 功能

| 视图 | 检测原理 |
|---|---|
| **ELA** | 错误级别分析：将照片按固定质量重新压缩，逐像素对比差异。被贴图/修改的区域压缩误差与周围不一致，会异常发亮 |
| **热力图** | 按 16×16 块统计压缩差异（RMS），P95 归一后以蓝→红色带叠加原图，直观定位可疑区域 |
| **噪声一致性** | 高通滤波提取传感器噪声纹理，贴上去的补丁颗粒感与周围明显不同 |
| **元数据** | 解析 EXIF（设备/时间/软件/GPS）、JPEG 量化表比对、编辑软件关键词扫描（Photoshop / 美图秀秀 / GIMP 等） |

辅助能力：

- **问题标注蒙版**：自动框出可疑区域并标注像素坐标范围（精度 ±16px，可开关）
- **双维度评分**：可疑度总分（满分 100，加权扣分）与可靠度评分（衡量本次检测可信度）分离，附逐项扣分明细
- **来源判定**：自动识别相机原图 / 社交软件压缩图 / PNG 截图等，压缩图会警示误报风险

## 使用建议

1. 先拿一张**确定没 P 过**的手机原图测一遍，记住"正常长什么样"，建立基线
2. 再测可疑照片，对比各视图差异
3. 可疑度高 ≠ 一定被 P 过；可疑度低 ≠ 干净。分数是规则参考，不是概率

## 局限（请务必阅读）

- 本工具只提供**值得怀疑的线索**，不能作为证据。涉及纠纷等重要判断请交给专业鉴定机构
- 经微信等社交软件压缩的图片会丢失大量痕迹且误报增多（工具会自动警示）
- 对「同图内复制粘贴挪动」（copy-move）类修改不敏感
- ELA 对调色、滤镜、美颜等全局处理不敏感
- PNG / 截图类图片 ELA 区分度下降，建议重点看热力图与噪声视图

## 隐私

照片**不会上传到任何服务器**，所有计算在浏览器本地完成。工具本身无任何外部依赖，可离线使用。

## 技术实现

单 HTML 文件（HTML + CSS + 原生 JavaScript），约 1300 行：

- JPEG EXIF/TIFF 解析器、量化表（DQT）解析均为手写实现
- 高斯模糊用三次盒式模糊近似（兼容不支持 `ctx.filter` 的 Safari）
- 处理了 iOS Canvas 静默白图限制、EXIF 方向校正、HEIC 解码回退等跨平台问题
- 设计方法论参考 [Anthropic frontend-design skill](https://github.com/anthropics/skills/tree/main/skills/frontend-design)
